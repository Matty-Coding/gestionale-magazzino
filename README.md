# Gestionale Magazzino

Applicazione web per la gestione di un magazzino, sviluppata come progetto reale su contratto.

## Features
- gestione utenti e ruoli
- gestione prodotti e magazzino
- interfaccia web per utilizzo operativo
- autenticazione e controllo accessi
- sistema di pagamenti 
- servizio automatico email di notifica

## Tech stack
- Python
- Flask
- Database relazionale
- HTML / Tailwind CSS / JavaScript

## Deployment
L’applicazione è deployata ed utilizzabile in ambiente di produzione.

Sono presenti dati fittizi per mostrare l'utilizzabilità, per eventuale simulazione di pagamenti utilizzare dati di test per [stripe](https://docs.stripe.com/testing?locale=it-IT).
